# TM GROUP H2 Landing

Готовый адаптивный лендинг для TM GROUP: водородные генераторы для экономии топлива на легковых автомобилях, грузовиках, коммерческом транспорте, спецтехнике и автопарках.

## Запуск
Откройте `index.html` в браузере или загрузите папку на хостинг.

## Структура
- `index.html` — готовая страница.
- `css/styles.css` — дизайн, адаптив, анимации, 3D-кнопки, неоновые элементы.
- `js/main.js` — мобильное меню, scroll reveal, калькулятор, имитация отправки формы.
- `assets/` — картинки, SVG-иконки и UI-элементы.
- `docs/` — исходное ТЗ.

## Важно
Формы сейчас работают как визуальный прототип. Для реального сайта нужно подключить обработчик заявок: CRM, Telegram, почту или backend.
