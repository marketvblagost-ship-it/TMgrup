# ТЗ для специалиста: лендинг TM GROUP / водородные генераторы для экономии топлива

## 1. Главная цель
Сверстать продающий лендинг по референсам из папки `mockups/`, сохранив тёмный премиальный автомобильный стиль: легковые авто, грузовики, двигатель, генератор, голубые H2-линии, зелёные 3D-кнопки и акцент на экономии топлива.

Критично: не переделывать концепцию под дом, квартиру, отопление или горячую воду. Это генераторы для автомобилей: легковые, коммерческий транспорт, грузовики, спецтехника, автопарки.

## 2. Что обязательно сохранить
- Общую тёмную стилистику первого макета.
- Первый экран с авто, грузовиком, двигателем и генератором.
- Блоки: проблема → решение → экономия → как работает → что получает клиент → для кого → калькулятор → доверие → FAQ → заявка.
- Цветовую схему: тёмно-синий фон, голубой неон, зелёные CTA, красный для проблемы.
- Бренд: везде `TM GROUP`, не HYDRO-DRIVE.
- География: `г. Шахты, Ростовская область`; отправка генераторов из Шахт по РФ.

## 9. Как это работает
4 шага:
1. Вода и электролиз — вода проходит электролиз в генераторе.
2. Получение водородно-кислородной смеси — образуется HHO-смесь.
3. Подача во впуск двигателя — смесь подаётся во впускной коллектор.
4. Более эффективное сгорание — топливо сгорает полнее и чище.

Добавить мягкую анимацию голубых линий через SVG path + `.neon-path`.

## 17. Анимации
### Кнопки
Использовать `.btn-3d` из `design/animations.css`: зелёный градиент, объём, медленный блик 1 раз в 4–5 секунд, hover-подъём на 2 px.

### Стрелки
Использовать `assets/ui/red_to_green_arrows_animated.svg` или `.flow-arrows`: последовательный pulse слева направо, красный → оранжевый → голубой → зелёный.

### H2-линии
SVG path с `stroke-dasharray` и `stroke-dashoffset`, класс `.neon-path`.

### Карточки
Hover: подъём 2–3 px, голубой/зелёный border, мягкое неоновое свечение.

### Scroll reveal
Секции появляются снизу на 20–30 px. Без резких эффектов.
