Это полный архив сайта.

Чтобы оформление не пропало:
1. НЕ открывайте index.html прямо из WinRAR.
2. Нажмите правой кнопкой по ZIP → Извлечь в папку.
3. Откройте index.html уже из распакованной папки.
4. В GitHub загружайте ВСЁ содержимое папки:
   index.html
   assets/
   css/
   js/
   max_icon.png

Если загрузить только index.html, сайт откроется без дизайна.
